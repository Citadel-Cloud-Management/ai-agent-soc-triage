ai-agent-soc-triage

LLM-powered SOC triage agent for automated security alert analysis, correlation, and response

Python 3.11+ AI/ML v0.1.0

Executive Summary

A Security Operations Center triage agent that uses LangChain and OpenAI to analyze security alerts from multiple SIEM platforms (Splunk, Microsoft Sentinel, Elastic SIEM). The system extracts indicators of compromise (IOCs), classifies alert severity via LLM, correlates events temporally and by IOC, looks up threat intelligence from VirusTotal/AbuseIPDB/OTX, and executes automated response playbooks. Outputs include automated ticketing (Jira/ServiceNow), notifications (Slack/Teams/PagerDuty), and YAML-driven playbook actions such as IP blocking.

Data Flow / Request Flow

  1. Alert Ingestion -- Alerts arrive from Splunk, Sentinel, Elastic, or a generic webhook receiver. Each connector normalizes to a SecurityAlert dataclass.
  2. IOC Extraction -- The IOC extractor scans alert titles, descriptions, and raw data for IPs, domains, URLs, and file hashes using compiled regex patterns.
  3. LLM Classification -- The alert classifier sends the normalized alert to GPT-4o via LangChain, returning severity (critical/high/medium/low/info), category (brute_force, malware, phishing, etc.), and recommended actions.
  4. Threat Intel Enrichment -- Extracted IOCs are concurrently looked up against VirusTotal, AbuseIPDB, and AlienVault OTX. Reputation scores and context are attached.
  5. Event Correlation -- The correlator groups alerts by shared IOCs and temporal proximity (configurable window, default 60 min), producing correlation clusters.
  6. Automated Response -- If severity meets the auto-respond threshold and auto-response is enabled, the playbook runner executes the matching YAML playbook. Tickets are created in Jira/ServiceNow. Notifications are dispatched to configured channels.
  7. Triage Result -- A structured TriageResult is returned containing classification, enrichment data, correlation info, and action results.

PCI-DSS and SOX compliance alert classification. Fraud detection correlation, wire transfer anomaly playbooks, regulatory incident reporting integration.

FedRAMP / NIST 800-53 control mapping. CUI/FOUO data exfiltration detection. CISA incident reporting automation. GovCloud SIEM connector support.

POS intrusion detection, supply chain compromise alerts. PCI scope monitoring, customer data breach playbooks with notification workflows.

Multi-tenant alert isolation, API abuse detection, credential stuffing correlation. SOC2 evidence collection for audit trails.

Production Readiness Checklist

  • Configure SIEM connector with production credentials and verify alert ingestion
  • Set OPENAI_API_KEY and validate LLM classification accuracy on sample alerts
  • Register threat intel API keys (VirusTotal, AbuseIPDB, OTX)
  • Customize YAML playbooks for organization-specific response procedures
  • Register action handlers in PlaybookRunner for each action type
  • Configure ticketing system (Jira/ServiceNow) credentials and project mapping
  • Set up notification channels (Slack/Teams/PagerDuty webhooks)
  • Test with enable_auto_response=False in dry-run mode
  • Deploy behind TLS-terminating reverse proxy for webhook endpoint
  • Set up monitoring, logging, and alerting for the triage engine itself
  • Configure log retention and audit trail for compliance
